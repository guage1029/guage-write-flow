# style.md — 写作风格（可直接修改）

> 这是开箱可用的基础风格模板。Step 4 创作和 Step 5 审校按本文件执行；Step 6 校验记录与当前规则的绑定关系，不认证语义风格质量。
> 作者身份、读者和领域见 [persona.md](persona.md)。本轮明确要求与事实准确性优先；已有文章默认保护原作者声音，明确要求转换风格时才按本文件转换。

## 默认表达与可修改字段

- **语气**：清晰、自然、克制。可改为正式讲解、轻松交流等符合读者与平台的表达，不强制聊天语气或个人口头禅。
- **句段节奏**：一段主要说清一个意思，长短随推理需要变化，兼顾手机阅读；不固定句数、字数或段落长度。
- **术语密度**：保留理解和操作所需的技术细节，解释主读者不熟悉的概念；不为所有术语硬造生活比喻。
- **结构偏好**：按读者的问题、材料和证据推进，不预设固定章节数。步骤、列表和表格只在便于理解或比较时使用。
- **开头与结尾**：开头交代具体问题、结果或真实触发点；结尾给出有证据的判断、适用条件或下一步行动，不固定开场白与结束语。
- **强调与标点**：加粗服务扫读，代码和标识符按 Markdown 语义排版；标点一致，不靠装饰符号制造重点。
- **避免的表达**：助手式开场、空洞拔高、无依据的绝对化结论、机械转场与重复总结；不为增加人味虚构冲突、对话、情绪或作者经历。

直接修改上述字段即可设定偏好。例如正式风格可写“语气正式，减少设问，保留完整术语与必要限定”；轻松风格可写“使用常用词和直接解释，允许设问，但不堆口头禅”。示例不代表已确认的个人偏好。

## Markdown 格式与修改边界

```markdown
# 主标题

可选副标题（普通段落）

开篇正文。

## 一、主要章节

### 1. 按需使用的子章节

#### ① 确有必要时使用的更细一级
```

完整长文恰好一个 H1，至少一个 H2，不跳级，不使用 H5 及更深层级。H2 默认用连续中文序号，本轮可另行指定不编号；H3 按并列条目需要编号。H4 必须在同一父级下连续使用 ①、②、③……。不要求每章都使用所有层级，不另设固定的“引言”或“写在最后”。

唯一 H1、至少一个 H2、层级连续、禁止 H5+ 和 H4 序号由脚本硬检查。改变这些格式约束还需同步检查脚本和测试，只编辑本文件不会改变脚本行为。

## 风格审校依据

以下六项在 style-review.md 中保留固定记录 ID，但依据当前配置判断，不预设某位作者的口吻：

1. **judgment**：判断有依据，区分事实、推断和一般结论，并写清适用条件。
2. **presence**：有真实经历时如实呈现；没有时使用直接解释或资料分析视角。
3. **explanation**：从主读者的问题推进，必要的机制、术语和限制得到解释。
4. **rhythm**：用词、句段节奏和转场符合当前设定的语气；正式表达不因缺少聊天感而判不通过。
5. **restraint**：不含助手腔、无意义拔高、虚构体验和没有材料支撑的夸张。
6. **structure**：结构服务本篇材料、读者与证据，标题承诺在正文兑现，不套用样文目录。

## 独立改写与全文复查

新写长文必须保留真实初稿，再按 style-review.md 逐段审查、改写和全文复查。有多少问题处理多少，不设改写数量、比例或轮数；本来合格的句段可保留并说明理由。不能靠批量填通过、添加口头禅或机械检查全绿代替实际审校。

必要的事实限定、代码、来源、样本量和计量口径不能为追求简短而删除。没有同题基线不比较优劣，没有真实记录不编造失败、耗时、情绪、用户反馈或亲历。

## 本人样文与长期偏好（可选）

默认没有私人样文，不影响执行。需要校准个人表达时，可提供本人文章或亲自修改的段落，说明哪些特征希望保留。经用户明确认可的偏好才能成为长期依据；样文中的事实不成为新稿证据，单篇的偶发表达不自动升级成所有文章的固定规则。

## 每轮复盘与持久化

- 每轮复盘实际用户反馈；局部要求默认只应用本轮，不自动修改本文件。
- 用户明确要求更新风格，或已授权持续维护时，按授权范围合并可复用规则，记录依据、日期、适用范围与例外。优先修订和去重，不无限累加禁令。
- 只确认选题、骨架或事实，不代表认可文章口吻；Agent 自评、生成句和脚本通过都不能作为用户偏好依据。
- 需要持久化但未获授权时，报告拟维护规则；不自行写回。没有新依据或只有本轮要求时，复盘结论为保持现有规则。
- 当前文章仍按本轮已明确的要求修改并复查；未持久化不影响本轮应用。手册实际变化后重新绑定审校记录。
- 安装目录不可写时报告未保存，并给出待合并内容。私人样文与反馈不自动公开或推送。
- 升级前备份本文件与 persona.md，与新版对比合并。维护 Skill 版本时仅递增补丁号 0.0.1。
